## Important source limits

The original internal links are preserved. Some point to code, logs, patches, scripts or other files in the full review archive that are deliberately not duplicated here. Those archive-local links may not resolve in this compact dossier; use the original `review(1).zip` for them.

This dossier does not rerun the experiments. The source review itself did not independently rerun Docker integration and explicitly limits its blind-discovery claim. Candidate prompts remain historical proposals, not evidence of reliable autonomous execution.

Reported usage and process-time values must not be read as billed monetary cost, equal computational effort, campaign wall time or current-model rankings.
